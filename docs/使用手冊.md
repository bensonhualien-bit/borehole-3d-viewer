# 鑽孔柱狀圖 3D 視覺化工具 — 使用手冊

![載入範例專案後的 3D 場景全景,彩色等高線曲面與鑽孔柱狀圖同時顯示](images/hero-3d.png)

## 啟動程式

- **線上版(建議)**:直接用瀏覽器開啟 <https://bensonhualien-bit.github.io/borehole-3d-viewer/> 即可使用,不需安裝任何軟體。
- **本機開發版**:在專案資料夾開終端機,第一次使用先執行 `npm install` 安裝套件,之後每次要打開都執行 `npm run dev`,再用瀏覽器開啟畫面顯示的網址(預設 `http://localhost:5173/`)。

打開後畫面上會有一個可以旋轉/縮放的 3D 場景,以及數個角落的浮動面板。沒有匯入資料前,畫面顯示的是內建的範例鑽孔;匯入的資料會保留在瀏覽器裡,重新整理網頁不會消失(想清掉自己匯入的資料、回到內建範例,見「左側:專案存讀」的「重設為範例資料」按鈕)。

## 範例檔案

專案資料夾裡的 `examples/` 收錄三個範例檔,可以用來快速認識各項功能,不用自己準備資料(使用線上版的話,先到 GitHub 專案頁的 `examples/` 資料夾下載檔案再上傳):

| 檔案 | 內容 | 怎麼載入 |
|---|---|---|
| `範例鑽孔資料.csv` | 12 支鑽孔的基本柱狀資料(CSV 格式不含 SPT-N/RQD 量測值,想看量測標籤請用 xlsx) | 從右上角「匯入鑽孔資料」面板上傳 |
| `範例鑽探報告.xlsx` | 14 支鑽孔(12 支 BH + 2 支 CPT),含 SPT-N、RQD、CPT 貫入曲線等量測資料 | 從右上角「匯入鑽孔資料」面板上傳 |
| `範例專案.json` | 一份已經畫好的完整專案:3 條剖面線、黏土層地層群組、開啟的 Kriging 彩色等高線、SF 填土自訂顏色、南側/北側兩個比對群組 | 從左上角「專案」面板按「開啟專案」載入 |

想快速看到大部分功能同時運作的樣子,建議先載入 `範例專案.json`。

## 3D 場景操作

| 操作 | 滑鼠動作 |
|---|---|
| 旋轉視角 | 按住左鍵拖曳 |
| 平移場景 | 按住右鍵拖曳 |
| 縮放 | 滾輪 |
| 查看分層資訊 | 滑鼠移到柱子上的某一層,畫面左上角會跳出鑽孔名稱、土質、深度範圍、備註(簡化點位模式下移到點位上只會顯示鑽孔名稱) |
| 查看 SPT-N / RQD 數值 | 滑鼠移到有量測資料的鑽孔柱子上,對應深度旁會顯示數值標籤(離開後消失) |

> 視角太貼近水平線(幾乎平視)時,地板網格會因為透視效果看起來很稀疏,屬於正常現象,把視角轉高一點即可。

**座標方位**:場景中央那組短座標軸,橘色是東西向(TE)、藍色是南北向(TN),垂直的綠色是高程,跟真實地理方位一致——3D 畫面裡的鑽孔相對位置可以直接跟廠區平面圖對照,不需要再另外旋轉或翻轉。

**地層等高線**:在右側「繪製地層」面板,任一條已命名的邊界線只要有 3 個以上不共線的點,旁邊就會出現「等高線開/等高線關」切換鈕,開啟後 3D 場景會顯示這條線內插出的起伏曲面與等值線;下方「等高線設定」可以調整等高線間距(主線/次線)、切換「純線段」/「有上色」顯示模式,以及切換內插演算法(TIN / Kriging)。點數不足 3 個時會顯示提示文字,不會出現切換鈕。

**內插演算法選擇**:「等高線設定」裡的「TIN」/「Kriging」單選決定所有等高線的內插方式。TIN 只在鑽孔涵蓋的範圍內產生結果,範圍外一律不畫;Kriging 則會繼續往範圍外推算出合理的起伏(適合想看整個場地趨勢、不只是鑽孔涵蓋範圍的情況)。選 Kriging 時,下方會多一個可展開的「自訂變異函數參數」,預設自動從點位資料估計,也可以手動輸入 range/sill/nugget 三個數字覆寫。

## 等高線數值圖例

![等高線數值圖例面板](images/contour-legend.png)

3D 場景裡只要有任一條剖面線同時開著「等高線」與「有上色」,畫面左上角「地層圖例」右側就會出現一個「等高線圖例」面板:

- 標題下面的小字「EL (m)」表示圖例的單位是高程。
- 面板上有一行小字標示目前是哪一條線的數值範圍(例如某條邊界線的名稱)。
- 右側是一條縱向漸層色條,由下往上對應低值到高值,旁邊列出 5 個刻度數字(最低值、最高值,以及中間均分的 3 個值)。

如果同時有兩條以上的線都開著「等高線 + 有上色」,圖例只會顯示第一條開啟的線的範圍,不會多個圖例並列。切換到 2D 剖面或多剖面比對畫面、關閉「有上色」、或該線的點數不足以算出曲面時,圖例會自動消失。切換 TIN/Kriging 或調整變異函數參數,圖例上的數字會跟著即時更新。

## 左上角:地層圖例與顏色自訂

固定顯示目前程式認得的土質代碼與對應顏色,色塊可以直接點擊來自訂顏色。

![點圖例色塊跳出的色彩選擇對話框,含標準顏色格與自訂按鈕](images/color-dialog.png)

**自訂一個土質代碼的顏色:**

1. 點圖例上想換色的色塊,會跳出「色彩選擇」對話框,標題會標示土質代碼與中文名稱
2. 對話框裡有一格 50 色的「標準顏色」,直接點一格可以選定
3. 想用其他顏色,按「自訂…」開啟系統原生色彩選擇器挑任意顏色
4. 不管挑哪一種,都只會先更新對話框裡「新增」那格預覽,不會立刻套用到畫面上
5. 按「確認」才真的套用;按「關閉」(或按 Esc 鍵)則放棄剛才的選擇,顏色完全不變

換色是**整類套用**:同一個土質代碼在 3D 柱狀圖、2D 剖面、圖例三處會同步變成新顏色,不是只改單一鑽孔的單一層。有自訂過顏色時,圖例下方會出現「恢復預設顏色」按鈕,按下會清空所有自訂色,三處都會變回原本的預設色。

> 顏色設定會存進瀏覽器,也會跟著「儲存專案」一起存進 `.json` 專案檔——換電腦或分享專案檔給別人,開啟後顏色設定會一起還原。

## 右上角:匯入鑽孔資料

![匯入鑽孔資料面板,含成功匯入訊息](images/data-uploader.png)

用來把內建範例資料換成你自己的鑽孔資料,支援兩種格式:

- **CSV**:欄位為鑽孔名稱、X座標、Y座標、地表高程、頂深、底深、岩性、顏色、備註;中/英文欄名都吃,編碼 UTF-8 或 Big5(Excel 常見匯出格式)自動判斷;顏色欄位可留空,程式會依土質名稱自動配色
- **Excel(.xlsx)**:直接上傳整理好的原始鑽探報告 Excel 檔,額外支援 SPT-N、RQD、CPT 貫入曲線等鑽探量測資料表

按「下載範本 CSV」可取得空白範本。成功會顯示「成功匯入 N 支鑽孔」;若有格式錯誤,會列出哪幾列有問題,但不影響其他正確資料列的匯入。

## 左下角:廠區配置圖

把一張真實的廠區配置圖(平面圖)貼到 3D 場景的地面上,跟鑽孔柱子做空間比對。

**操作步驟:**

1. 用檔案選擇框上傳一張圖片
2. 上傳後畫面會顯示圖片預覽,滑鼠滾輪在預覽圖上可以放大/縮小(1x~5x),方便點準確的位置
3. 在圖上依序點選 **2 個你知道真實座標的位置**
4. 在「點1」「點2」對應的欄位輸入該點的**真實 X、真實 Y 座標**(跟鑽孔資料用同一套座標系統)
5. 確認或修改「地面高程 (EL, m)」欄位
6. 按「套用」——3D 場景地面上就會出現這張圖,自動算出正確的縮放、旋轉、位置
7. 校準結果會存在瀏覽器裡,重新整理網頁或關掉程式再打開都還在
8. 想換一張圖或重新校準,按「清除」再重新上傳

**在 3D 場景中微調圖片位置:**套用後的圖片可以直接用滑鼠拖曳微調,拖曳結果自動存到本機;面板上的「鎖定位置」勾選框可以固定圖片避免誤拖。

**常見錯誤訊息:**

| 訊息 | 原因 |
|---|---|
| 請先點選 2 個參考點並輸入座標 | 還沒點滿 2 個點,或欄位還沒填 |
| 座標與高程不可留空 / 必須是數字 | 欄位空白或打了非數字內容 |
| 兩個參考點距離太近,請重新點選 | 2 個點在圖上或真實座標幾乎重疊,無法算出可靠的縮放/角度 |
| 圖片太大,請換小一點的圖片再試一次 | 圖片超過瀏覽器可以儲存的大小上限 |

## 右下角:顯示設定

- **鑽孔顯示模式切換**:在「完整柱狀圖」與「簡化點位」間切換,簡化模式每支鑽孔只顯示一個小圓點與名稱,適合鑽孔數量多、只想快速看整體分布位置的情境
- **顯示網格/隱藏網格**:開關地面網格(1m 次線虛線、5m 主線實線)與 3D 場地四周的高程參考網格牆

切換顯示模式或網格開關,都不會影響已上傳的資料或校準設定。

## 手動繪製地層剖面線

在 3D 場景右側面板(「繪製地層」)可以依鑽孔的實際分層,手動點出地層邊界剖面線。

**畫一條邊界線:**

1. 勾選「繪製地層」開啟繪製模式
2. 選擇深度模式:「吸附地層界面」(新增點時自動吸附到最近的分層邊界,適合沿著實際地層界面畫線)或「自由深度」(不吸附,精度 0.01m/1公分,適合畫任意假想面)
3. 輸入邊界線名稱、選色,按「新增邊界線」
4. 依序在 3D 場景中點擊不同鑽孔柱子上的位置,新增剖面點——點擊前游標旁會即時顯示即將落點的深度數字
5. 點錯了可以按「悔恨上一點」撤銷最後一個點
6. 畫完按「完成此線」結束這條線(之後仍可「繼續編輯」加點)

同一支鑽孔在同一條線上再點一次,不會變成第二個點,而是直接更新這個點的深度。

**編輯既有的線:**

- 每條線可以展開(▸/▾)看目前所有點,個別點的深度可以直接在數字輸入框修改,或按「✕」刪除該點
- 「繼續編輯」重新進入這條線繼續加點;拖曳 3D 場景中已存在的點可以直接調整深度(拖曳不受目前深度模式的吸附限制)
- 「顯示中/已隱藏」切換這條線在畫面上顯不顯示;「刪除」整條移除
- 線的顏色、名稱都可以直接在清單上修改

**組成地層:**

在下方「地層」區塊輸入名稱、選色、按「新增地層」,再幫這個地層指定「上界」「下界」各對應哪一條邊界線(下拉選單也可以直接「+ 繪製新邊界線」),方便標記同一個地層的頂底範圍。

## 2D 剖面圖檢視

![2D 剖面圖檢視](images/profile-2d.png)

按畫面上方「切換為2D剖面」可以切換到傳統的 2D 剖面圖檢視(按「切換為3D視圖」切回 3D)。2D 檢視使用同一份剖面線資料,不是另外一份。

- **鑽孔勾選清單**:2D 檢視有自己獨立的鑽孔顯示勾選清單(全選/清除),跟 3D 場景各自獨立;選到 2 支以上鑽孔後,清單會自動收合成「已選 N 支鑽孔 ▾」小標籤,避免擋住畫面,點一下可以重新展開
- **水平軸距離模式**(清單面板內的選項):
  - **投影剖面距離**(預設):用總體最小平方法找出這幾支鑽孔的最佳剖面線,再算每支鑽孔投影到這條線上的距離
  - **鑽孔間直線距離**:依剖面線上的順序,累加相鄰鑽孔之間的實際 2D 直線距離
  - 柱子寬度與畫面自動縮放範圍固定用「投影剖面距離」計算,不受目前選擇哪種模式影響,只有柱子的**位置**會跟著所選模式改變
- **繪製/編輯剖面線**:操作方式與 3D 場景相同(繪製地層勾選框、深度模式、新增邊界線、點擊新增點等),點擊前後都會即時顯示深度數字;2D 的連線只連接水平位置相鄰的兩點(傳統剖面圖的折線畫法),與 3D 場景「所有點兩兩相連」故意不同
- **平移/縮放**:滾輪縮放,按住右鍵拖曳平移
- **匯出 PDF**:選到 2 支以上鑽孔後,鑽孔勾選清單面板下方會出現「匯出 PDF」按鈕,詳見下方「2D 剖面匯出 PDF」一節
- **柱寬設定**:右下角另有一個獨立的「柱寬設定」面板可以調整柱狀寬度,詳見下方「柱寬設定」一節

### 柱寬設定

![柱寬設定面板展開,含柱寬上限與密度係數兩個滑桿](images/bar-width-panel.png)

2D 畫面(單一剖面與多剖面比對都適用)右下角有一個「柱寬設定」面板,預設收合成小按鈕「柱寬設定 ▾」,點一下展開;展開時右上角有「▴ 收合」按鈕可以收回。

面板內有兩個滑桿:

- **柱寬上限**(0.5%~5%,步進 0.1%,預設 2%):柱狀寬度佔剖面總跨距的比例上限,少孔、跨距小的場地會吃到這個上限
- **密度係數**(0.10~0.80,步進 0.05,預設 0.35):鑽孔數量多、彼此靠很近時,柱寬改用「平均間距 × 這個係數」計算,避免柱子隨孔數增加而擠成一片

拉動滑桿畫面即時套用,設定值會存進瀏覽器,下次開啟保留;下方「恢復預設(2% / 0.35)」按鈕可以一鍵還原成 2% / 0.35。這組設定同時套用在螢幕 2D(單一剖面與多剖面比對)與匯出 PDF,兩邊視覺一致。

> 位置太接近的鑽孔(中心距小於柱寬)會自動判定成同一群、並排錯開,群內每支仍維持完整柱寬、彼此不重疊,整群置中在成員的平均位置;點擊選取也會對應到正確的鑽孔,不會因為並排而選錯。

### 2D 剖面匯出 PDF

- **單一剖面畫面**:在左側「選擇鑽孔(2D 剖面)」面板下方,選滿 2 支以上鑽孔後會出現「匯出 PDF」按鈕(不足 2 支時停用)
- **多剖面比對畫面**:選單面板(見下方「多剖面比對」)裡有「匯出 PDF(一群一頁)」按鈕,還沒有建立任何群組時停用

**匯出內容**:A3 橫式頁面,含圖框、圖名欄(圖名、匯出日期、縱向放大倍率、鑽孔數量與清單)、圖例(只列出該頁實際出現的土質代碼,顏色跟畫面上的自訂顏色一致)、繪圖區左右兩側的高程軸,以及剖面圖本身(地層色塊、剖面線連線、格線)。

剖面一律自動縮放到完整涵蓋所有選取鑽孔的深度範圍匯出,不受畫面目前的縮放/平移狀態影響,結果穩定可重現;縱向會依資料形狀自動放大(以 0.5 倍為級距,例如 1.5×、2×、2.5×……),圖名欄會註明實際用了幾倍。多剖面比對匯出時,每個鑽孔群組各自成一頁,合成一份多頁 PDF 一次下載。

匯出進行中按鈕會顯示「匯出中…」並暫時停用,完成即自動下載檔案;失敗時會跳出訊息告知錯誤原因。

> 目前的匯出還沒有 SPT-N 貫入曲線、黑白土壤花紋、正式公司圖框座標等制式出圖項目,匯出的是「畫面上看到的樣子」加上圖框、圖名欄與圖例,不是完整仿照制式工程圖。

### 多剖面比對

![多剖面比對畫面,南側剖面/北側剖面兩個群組面板上下堆疊顯示](images/comparison.png)

在 2D 剖面圖畫面按「多剖面比對」可以切換進入比對模式,按「返回單一剖面」切回原本的單一剖面圖畫面。

- **選單收合**:軸模式(投影剖面距離/鑽孔間直線距離)與鑽孔群組管理選單預設固定顯示在畫面正中央上方,展開時右上角有「▴ 收合」按鈕可以收成一個小按鈕「選單 ▾」,不擋住底下的剖面圖,點一下再展開——收合/展開狀態會記住,下次重新打開網頁維持上次的狀態
- **建立鑽孔群組**:選單裡按「+ 新增群組」,勾選任意幾支鑽孔、輸入群組名稱,按「建立」(未勾選任何鑽孔無法建立);已存在的群組可以點名稱直接改名、按「編輯鑽孔」調整成員後按「完成」、按「刪除」整組移除
- 每個群組各自畫成一張 2D 剖面圖,由上而下堆疊顯示,方便直接比較不同群組(不同剖面走向)的地層趨勢
- **垂直(高程)縮放/平移是每個面板各自獨立**:滾輪縮放或拖曳任一面板的垂直方向,只會改變那一個面板,不會影響其他面板;水平方向(左右平移/縮放)本來就是各自獨立。之後只有兩種情況會讓某個面板的垂直範圍重算:該面板所屬的群組剛建立,或該群組自己的鑽孔成員被修改——這時只有那一個面板會重算,其他面板保留使用者手動調整過的視角不受影響。剛進入比對畫面時,所有面板會先用「所有群組鑽孔的聯集」算出同一個初始高程範圍,方便一開始就能互相比對
- 面板完全可互動,可以直接在任一面板新增/拖曳剖面線點位——因為剖面線資料是全域共用的,同一支鑽孔如果同時出現在多個群組面板裡,在任一面板編輯會立刻反映到其他面板
- 水平軸距離模式(投影剖面距離/鑽孔間直線距離)是全域設定,所有群組面板共用
- 匯出 PDF 按鈕在選單裡,詳見上方「2D 剖面匯出 PDF」一節

## 左側:專案存讀

面板標題「專案」,固定顯示在畫面左上角,跟「地層圖例」(及等高線圖例)排在同一欄——圖例面板變高時(例如出現「恢復預設顏色」按鈕或錯誤訊息),「專案」面板會自動被往下推開,兩者不會互相重疊。

- **儲存專案**:把目前的鑽孔資料、廠區配置圖校準、所有剖面線/地層資料、等高線設定、自訂土壤顏色、柱寬設定,整包存成一個 `.json` 檔下載
- **開啟專案**:選擇先前存的 `.json` 專案檔,一次還原所有資料與畫面設定
- **重設為範例資料**:清掉瀏覽器裡保存的鑽孔資料、剖面線、地層群組、顏色設定等,回到內建的範例場景——想清空自己匯入/畫過的資料重新開始時用這顆按鈕,不用手動清瀏覽器資料。按下後會先跳出確認對話框,確定才會真的清除並重新整理頁面。

## 目前的限制(尚未支援)

- 廠區配置圖只能存一組,無法同時切換多張圖或多組校準
- 目前沒有正式的雲端協作/多人同時編輯機制,專案資料以本機瀏覽器 localStorage 與手動匯出的 `.json` 檔為主
- 匯出 PDF 目前沒有 SPT-N 貫入曲線、黑白土壤花紋、正式公司圖框座標等制式出圖項目
- 多剖面比對的各群組面板垂直比例各自獨立,目前沒有「所有頁面統一同一個垂直比例」的選項
